Système intelligent de commande au restaurant

À propos du projet

Smart Restaurant Ordering System est une application web conçue pour simplifier le processus de commande au restaurant. Elle permet aux clients de consulter le menu, de sélectionner des repas et de passer des commandes afin d’être servis directement à leur table.

Objectifs

• Numériser le processus de commande au restaurant.
• Améliorer l’expérience des clients.
• Faciliter la communication entre les clients et le personnel du restaurant.
• Réduire les erreurs lors de la prise des commandes.

Fonctionnalités

• Identification du numéro de table.
• Consultation du menu du restaurant.
• Sélection des repas et gestion des commandes.
• Envoi des commandes.

Remarque : seules les fonctionnalités réellement implémentées dans la version actuelle doivent être mentionnées.

Technologies utilisées

• Frontend (interface utilisateur) : HTML, CSS, JavaScript.

3. Configurer la base de données, si nécessaire.
